
# QuickBite - Food Delivery System

## About the Project
QuickBite is a responsive food delivery web application that allows users to browse food items, add products to their cart and place orders.

## Features
- Attractive homepage
- Food menu with categories
- Search functionality
- Add to cart
- Increase and decrease item quantities
- Remove items from cart
- Automatic bill calculation
- Customer checkout form
- Order confirmation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Browse the menu and add food items to your cart.
5. Proceed to checkout and place an order.

## Project Structure
- index.html - Website structure
- style.css - Styling and responsive design
- script.js - Food menu, cart and checkout functionality
